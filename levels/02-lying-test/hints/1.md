## Подсказка 1 · куда смотреть

Сравни, на каких строках тест проверяет длину и на каких строках
падает у пользователя. Чем латиница отличается от кириллицы с точки
зрения памяти?

Проверь сам:

```
cat > /tmp/len.go <<'EOF'
package main

import "fmt"

func main() { fmt.Println(len("Nike"), len("Найк")) }
EOF
go run /tmp/len.go
```
