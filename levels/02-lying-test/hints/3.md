## Подсказка 3 · объяснение

Символы (руны) считает пакет unicode/utf8:

```
if utf8.RuneCountInString(name) > MaxNameLen {
```

Длинную строку в тесте удобно строить через strings.Repeat:

```
{"60 символов кириллицей", strings.Repeat("ж", 60), false},
{"ровно 100 символов кириллицей", strings.Repeat("ж", 100), false},
{"101 символ кириллицей", strings.Repeat("ж", 101), true},
{"только пробелы", "   ", true},
```

Главный урок уровня: тест на границу пишут ровно на границе
(100 и 101), а не «где-то рядом». И тест должен хотя бы раз
покраснеть на сломанном коде, иначе непонятно, проверяет ли он
что-нибудь. Так и работает мутационное тестирование в make check.
