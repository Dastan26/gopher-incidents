# GOPHER-2 · «Не длиннее 100 символов» на названии из 60 букв

Приоритет: высокий · Темы: строки и UTF-8, табличные тесты, граничные значения

## Что видит пользователь

Контент-менеджер создаёт бренд с казахским названием из 60 букв.
Форма показывает под полем: «Не длиннее 100 символов». То же название
латиницей сохраняется без проблем.

```
curl -i -X POST localhost:8080/brands \
  -d '{"data":{"type":"brands","attributes":{"nameKz":"Солтүстік Қазақстан облысының сүт өнімдері зауыты «Ақ бидай»","nameRu":"Молочный завод"}}}'
HTTP/1.1 422 Unprocessable Entity
```

## Самое неприятное

В CI всё зелёное. TestValidateName в internal/brand/brand_test.go
проходит, хотя прямо проверяет длину названия. Тест есть, но он
не ловит баг, ради которого написан.

## Требования к названию (из постановки)

- Обязательное.
- Пробелы по краям не считаются, название из одних пробелов пустое.
- Не длиннее 100 символов включительно, на любом языке: латиница,
  кириллица, казахские буквы.

## Задание

1. Сначала тест. Добавь в TestValidateName случаи, которые ловят этот баг.
   Тест должен покраснеть на текущем коде.
2. Потом код. Почини ValidateName, тест зеленеет.

make check на этом уровне проверяет и твои тесты. Он подсовывает
в validate.go несколько заведомо сломанных версий (мутантов), и твой
тест обязан упасть на каждой. Если мутант выжил, значит тест не покрывает
одно из требований выше.
