## Подсказка 3 · объяснение

map нужно создать до первой записи:

```
return &Memory{nextID: 1, items: make(map[int]brand.Brand)}
```

Проверка ключа делается формой comma-ok: второе значение говорит,
был ли ключ.

```
b, ok := m.items[id]
if !ok {
    return brand.Brand{}, brand.ErrNotFound
}
```

Хендлер уже умеет превращать brand.ErrNotFound в 404: посмотри метод fail
в internal/httpapi/handler.go. Хранилище только должно честно сообщить,
что бренда нет. Какой HTTP-статус вернуть, решает HTTP-слой, а не хранилище.
