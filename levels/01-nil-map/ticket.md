# GOPHER-1 · Сервис справочника брендов не поднимается

Приоритет: критичный · Темы: map, нулевые значения, comma-ok, чтение стектрейса

## Что видит пользователь

Фронт MDM не может открыть справочник брендов: все запросы
к API падают с Network Error. Под сервиса в CrashLoopBackOff.

В логе при старте:

```
panic: assignment to entry in nil map

goroutine 1 [running]:
gopher-incidents/internal/store.(*Memory).Create(...)
main.seed(...)
```

## И ещё одно, от QA

После того как сервис подняли руками на старой версии, QA заметил:
запрос несуществующего бренда возвращает 200 и пустой бренд с id 0.
Фронт показывает пустую карточку вместо экрана «Бренд не найден».

```
curl -i localhost:8080/brands/999
HTTP/1.1 200 OK
{"data":{"type":"brands","id":"0", ...
```

## Критерии готовности

- Сервис стартует: make run, затем curl -s localhost:8080/brands отдаёт три бренда.
- Store.Get для несуществующего id возвращает ошибку brand.ErrNotFound.
- GET /brands/999 отвечает 404 в формате JSON:API.
- make check зелёный.

## С чего начать

```
make run
```

Прочитай стектрейс снизу вверх: где началось и где упало.
