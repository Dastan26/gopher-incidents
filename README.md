# Дежурный по проду

Учебная игра по бэкенду на Go. Есть настоящий маленький сервис:
справочник брендов с JSON:API, как у MDM. Каждый уровень — инцидент:
сервис ломается, ты получаешь тикет и чинишь его, пока `make check`
не позеленеет.

Теорию заранее учить не нужно. Начинай с тикета, а нужное объяснение
придёт из подсказок, когда упрёшься.

## Подготовка (один раз)

```bash
brew install go
cd ~/gopher-incidents
make status
```

## Как играть

```bash
make level-1   # начать инцидент: создаётся ветка level-01 с поломкой
make ticket    # перечитать тикет
make run       # запустить сервис на :8080 и воспроизвести баг
make check     # проверить фикс
make hint      # следующая подсказка (их три, от «куда смотреть» до объяснения)
make status    # доска инцидентов: время и подсказки по каждому
make reset     # начать текущий инцидент с нуля
```

Когда `make check` зелёный:

1. Закоммить фикс: `git commit -am "fix: ..."`.
2. Сделай `git show | pbcopy` и вставь Claude. Он сделает ревью,
   как тимлид в настоящем MR.

## Правила

- Не открывай `levels/*/break.patch`, приёмочные тесты и мутантов.
  Там лежит ответ.
- `git log -p` на ветке уровня показывает коммит с поломкой. В жизни
  `git log` и `git blame` — законные инструменты дежурного, но здесь
  пользуйся ими только после третьей подсказки.
- Квиз «Гофер-маршрут» — пятиминутная разминка после инцидента,
  а не основное занятие.

## Как устроено

```
cmd/api/              точка входа, graceful shutdown
internal/brand/       модель и валидация (без HTTP и хранилища)
internal/store/       хранилище в памяти
internal/httpapi/     хендлеры, JSON:API, middleware
levels/NN-*/          тикет, подсказки, поломка, приёмочные тесты
scripts/              движок игры
```

`make check` собирает проект, гоняет `go vet`, твои тесты и приёмочные
тесты уровня. Приёмочные тесты подкладываются в пакеты только на время
проверки. На некоторых уровнях он ещё подменяет файл заведомо сломанными
версиями (мутантами) и проверяет, что твои тесты их ловят.

## Уровни

| # | Инцидент | Темы |
|---|----------|------|
| 1 | Сервис падает на старте | map, нулевые значения, comma-ok, стектрейс |
| 2 | Тест зелёный, а кириллица не сохраняется | UTF-8, табличные тесты, границы, мутанты |
| 3 | Фронт пишет «Сохранено», а бренд не создан | ResponseWriter, статусы, заголовки |

Дальше по плану: гонка данных в хранилище, Postgres и N+1, транзакции,
авторизация через Keycloak, воркер на горутинах, Kafka и идемпотентность,
под, который не останавливается по SIGTERM.
